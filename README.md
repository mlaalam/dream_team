# Digital Services Company

A simple and modern **company portfolio website** built with **React.js**, **Axios** and **JSON Server**.

The website presents our company, services, monthly subscription plans, team and contact information.

## 🎯 Project Goal

The goal of this project is to create a modern and professional website for a digital services company.

The website allows visitors to:

- Discover our company
- Learn about our services
- View monthly subscription prices
- Discover our team
- Contact our company

The project focuses on practicing:

- React.js
- JavaScript / JSX
- React Router
- Axios
- REST API
- JSON Server
- Reusable components
- Responsive design
- Modern UI design

## 🚀 Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Go to the project folder:

```bash
cd rtk-query-todo
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```
